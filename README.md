# Start local development server

## 🌐 Deployment

Can be deployed instantly to any static host:
- **Vercel**: `npx vercel`
- **Netlify**: `npx netlify deploy`
- **GitHub Pages**: Push to `gh-pages` branch.
- **Firebase Hosting**: `firebase deploy --only hosting`
